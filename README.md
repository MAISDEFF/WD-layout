# WD — Адаптивный лендинг

Адаптивная вёрстка одностраничного сайта по готовому макету с использованием HTML5 и CSS3.

Проект создан для практики вёрстки, работы с Flexbox, CSS Grid и адаптации интерфейса под различные размеры экранов.

## 🔗 Демонстрация

[Посмотреть проект](https://maisdeff.github.io/WD-layout/)

## 📌 Особенности проекта

- Адаптивная вёрстка с использованием медиа-запросов
- Построение сеток с помощью Flexbox и CSS Grid
- Интерактивная галерея с эффектами при наведении
- Форма обратной связи с HTML5-валидацией
- Подключение шрифтов Google Fonts
- Встроенное видео
- CSS-переходы и эффекты наведения

## 🛠️ Используемые технологии

- **HTML5** — структура и разметка страницы
- **CSS3** — стилизация и оформление
- **Flexbox** — расположение элементов
- **CSS Grid** — сетка изображений
- **Media Queries** — адаптация под разные экраны
- **Git** — контроль версий

## 🎯 Цель проекта

Закрепить навыки HTML и CSS, научиться переносить дизайн-макеты в браузер и создавать адаптивные интерфейсы.

В процессе разработки были реализованы основные секции лендинга: шапка сайта, блок информации, портфолио, галерея изображений, форма обратной связи и подвал.
